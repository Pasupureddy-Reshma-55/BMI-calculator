# 💪 BMI Calculator

## 📌 About The Project

The **BMI (Body Mass Index) Calculator** is a simple, interactive, and user-friendly web application designed to calculate a person's Body Mass Index based on their weight and height.

The application allows users to enter their weight and height and calculate their BMI instantly. Based on the calculated BMI value, it displays different health categories such as Underweight, Normal, Overweight, and Obese.

It provides a clean and attractive interface with a colorful BMI gauge, dynamic result messages, and Metric and Imperial unit selection options.

This project is developed using HTML, CSS, and JavaScript to demonstrate basic front-end web development concepts.

## ✨ Features

- Calculate Body Mass Index (BMI).
- Simple and attractive user interface.
- Supports Metric and Imperial unit selection.
- Displays BMI values instantly.
- Shows four BMI categories:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Dynamic messages based on BMI results.
- Colorful BMI gauge and category indicators.
- Input validation for weight and height.
- Responsive layout for smaller screens.

## 🛠️ Technologies Used

- **HTML5** – Creates the structure of the application.
- **CSS3** – Provides styling, colors, layout, and responsive design.
- **JavaScript** – Handles BMI calculations, input validation, and dynamic results.

## 📊 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25 – 29.9 | Overweight |
| 30 and above | Obese |

## ⚙️ How It Works

1. Open the BMI Calculator application.
2. Select Metric or Imperial.
3. Enter your weight.
4. Enter your height.
5. Click the Calculate BMI button.
6. View your BMI value and corresponding category.
